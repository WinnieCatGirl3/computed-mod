    About¶

    Fork of The Propulsion Team's Computed, re-themed and reworked with original CC0 assets and my own spin on it. LuaJ powers one sandboxed VM per computer while the Computed engine owns graph scheduling, safe Minecraft endpoints, persistence, networking, the editor, monitor rendering, and integrations.

    Program format 3 stores one root graph and an embedded Lua definition library. Legacy graphs, Functions, Sections, JSON custom nodes, CMP1, and CMP2 are intentionally discarded or rejected without migration.

    Runnable code examples live under docs/lua/examples in the repository.

    Building¶

    Build and verify with:

    ./gradlew clean check build
